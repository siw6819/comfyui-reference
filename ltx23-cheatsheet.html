Schedulers vs Manual Sigmas
Sigmas are noise levels — a list of numbers from high (lots of noise) to low (nearly clean). Each number is one denoising step. A scheduler calculates this list automatically. Manual sigmas let you write the list yourself, giving you direct control over how noise is removed at each step.
What the numbers mean
1.0
Pure noise — start of generation. Always the first value.
0.5 – 0.7
Mid-range — structure and motion being laid down.
0.0 – 0.05
Near-clean — fine detail and sharpening. Last value.
LTXVScheduler — parameters
steps
20 – 50
How many sigma values to generate. Each = one denoising step. Dev model: 20–50. Distilled: use manual sigmas instead.
max_shift
2.05
Curve shape for high-res / high frame-count latents. Higher = more denoising energy in early steps. Leave at default unless tuning for a specific resolution.
base_shift
0.95
Same as max_shift but for low-res / low frame-count latents. Scheduler interpolates between base and max depending on token count. Leave at default.
stretch
true
Snaps the last non-zero step to exactly the terminal value. Almost always want this on — without it the schedule may not land cleanly at your chosen terminal.
terminal
0.0 – 0.1
0.0 = fully clean final step. 0.05 = leaves a trace of noise, can mask artefacts and harsh edges. Try 0.05 if output has banding.
Key asymmetry — no start sigma control
LTXVScheduler controls where the schedule ends (terminal) but not where it starts. The start is determined automatically from the shift parameters and your latent's token count. To start from e.g. 0.9 instead of 1.0 — anchoring tightly to your input image — you need manual sigmas. This is the main practical reason to reach for manual sigmas over the scheduler.
Manual Sigmas — required for distilled + stage 2 refinement
Distilled · stage 1 · 8 steps DEFAULT
1.0, 0.9933, 0.9850, 0.9767, 0.9008, 0.6180, 0.4219, 0.0
Official default from Lightricks. Steps stay close together at the high end (structure), then a bigger jump down to 0.618, then 0.42 for detail, then hard stop at 0. 8 values = 8 steps. CFG = 1.0–1.5.
Stage 2 refinement · after spatial upscale REFINE
0.5, 0.421875, 0.0
Only 3 steps. Starts mid-range (0.5) — you're refining an already-structured latent, not generating from scratch. Equivalent to roughly denoise = 0.47. Keep stage 2 denoising strength 0.35–0.55.
Distilled · 5-step lighter variant FAST
0.987, 0.85, 0.725, 0.422, 0.0
Community-found 5-step schedule. Bigger jumps = faster but coarser. Ending on 0.0 gives a pure denoise final step (no grain). Try 0.05 as the last value if output looks too sharp.
Tuning logic
Too noisy / grainy
Lower the first value slightly (e.g. 1.0 → 0.987). Less initial noise = calmer start.
Too soft / blurry
Add more steps in the 0.4–0.7 range. More mid-range steps = more detail pass time.
Artefacts at end
Try ending on 0.05 instead of 0.0. A small final sigma leaves a trace of noise that can mask hard artefacts.
Logo / watermark glitch
Known LTX issue on long videos. Adjust first sigma value up slightly and ensure prompt is long enough to guide the full clip.
Output Dimensions
Video diffusion models operate on patches/tiles. Dimensions that aren't multiples of 64 get padded internally, which wastes compute and can cause subtle edge artefacts. Always snap to the nearest valid value.
Common valid resolutions
1280 × 704  (≈ 16:9, not 720)
1024 × 576
896 × 512
768 × 448
512 × 512
Avoid these
1280 × 720  (720 ÷ 64 = 11.25 ✗)
1920 × 1080
1280 × 768  (768 ÷ 64 = 12 ✓ but 1280 ÷ 64 = 20 ✓ — actually fine)
any odd number
720 is the classic trap — looks standard but breaks the multiple-of-64 rule. Use 704 instead.
Rule
Both width AND height must be multiples of 64. Check each dimension independently.
Frame count
Same rule applies — frame counts should be multiples of 8, ideally (8, 16, 24, 32...).
After upscaling
If spatial upscaling x2, your generation res × 2 should also be valid. 512×512 → 1024×1024 ✓
